# ニュース定点観測

自分で選んだ分野(政治・経済・会計・法律・国際・社会…)のニュースだけを、毎朝自動で集めて表示する個人用ニュースボードです。

- **本体(リアルタイム版・カテゴリ管理あり)**: [claude.ai のArtifact](https://claude.ai/code/artifact/77481c43-0519-4a44-8502-27c32be1c994)
  - 分野の追加・削除・並び替え・キーワード編集はここで行う
  - 毎朝7:00 JSTに自動でWeb検索してニュースを追加する仕組みが動いている(claude.ai側のスケジュールタスク)
- **このリポジトリ(GitHub Pages・静的ミラー)**: スマートフォンなどからclaude.aiのリンクを介さずに見られるようにするための、読み取り専用の静的コピー

## 仕組み

`data.json` に本体からエクスポートしたカテゴリ・記事のスナップショットを保存し、`generate.py` で `index.html` を生成しています。

```
python3 generate.py
```

## 同期の運用方針

2026-09-14以降、便利帳プロジェクトと同じ方式(ローカルのClaude Code CLIで`/schedule`コマンドを使い、GitHub App経由でこのリポジトリへのアクセスを許可する方式)で、**自動同期・自動pushが毎日動いています**。

- claude.ai側で毎朝ニュースを自動収集した後、その約半日後に自動同期タスクが起動し、Artifactの最新データを取得して `data.json` を更新・`generate.py` を実行し、差分があればコミット・pushします
- 手動で今すぐ最新化したい場合は、「ニュース定点観測をGitHubに同期して」とClaudeに頼めば、同様に `data.json` を最新化して `generate.py` を実行し、pushします
- 自分で更新したい場合は、claude.aiのArtifactからカテゴリ・記事データを確認し、`data.json` を書き換えて `python3 generate.py` を実行してください

## 公開設定

GitHub Pages の設定で、ブランチ `main` のルート(`/`)を公開ソースに指定してください。
